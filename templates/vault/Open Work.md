# Open Work

The single queue of open items, each a `- [ ]` checkbox line so session start and `/bearings` can read it.
Tag each one with its project, as a trailing `` — `project` `` at the end of the line, so it can be scanned or filtered by project later.
A line whose text starts with your name (the `user_name` set in `config/agent.md`, e.g. `- [ ] Alex: ...`) is a call for you specifically and surfaces under Captain's Call; everything else is next work for the agent.
Add new items at the top; move a finished item to its project's own note or to `Archive/` instead of deleting the line, unless it never mattered enough to keep - checking the box (`- [x]`) also drops it from the open count.
